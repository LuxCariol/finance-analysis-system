# GitHub 仓库简介

## 短描述

基于 Spring Boot、Vue 3 和 uni-app 的金融财务分析系统，支持金蝶 Excel 报表导入、编码映射、ETL 数据转换、财务比率分析、损益预测与投资测算。

## 完整描述

金融财务分析系统是一个面向企业财务场景的全栈实训项目，覆盖从金蝶 Excel 报表导入、标准编码映射、数据转换到财务指标分析和经营预测的完整链路。

项目后端基于 Spring Boot 2.7 和 MySQL 8，包含 Web 管理端、管理 REST API 和移动端业务 API；现代 Web 端采用 Vue 3 + Element Plus + ECharts，提供经营驾驶舱、报表导入、公司/用户/角色/字典管理、账龄分析、编码配置、数据转换、比率分析和资讯管理；移动端采用 uni-app，提供经营报告、三大报表明细、财务分析、比率分析、账龄与科目余额、损益预测和投资预测。

系统已内置 2021 年 12 个月演示数据和 Excel 样例，支持利润表、资产负债表、现金流量表、科目余额表及多类账龄分析的解析和导入，并实现 NPV、IRR、回收期、项目现金流和全资本现金流等投资测算功能。
