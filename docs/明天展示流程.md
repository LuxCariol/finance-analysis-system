## 四、开场话术

可以这样介绍：

> 老师好，我的实训题目是金融财务分析系统。原始资料里已经有 SQL、金蝶报表样例和部分 JSP 页面，但后端控制层、服务层和数据访问层缺失，导入逻辑也不完整。我在一个全新的 `financial-analysis` 目录中重建了可运行的后端，新增了 Vue 3 + Element Plus 的现代 Web 管理端，保留原 JSP 页面作为兼容版本，同时完成了移动端 REST 接口和 uni-app 页面。

> 系统主流程是：公司在后台建立档案，导入利润表、资产负债表、现金流量表、科目余额表和账龄数据，配置编码映射和算法规则，再通过数据转换生成标准化指标，供 Web 端和移动端做财务分析、损益预测和投资测算。

## 十一、老师可能提问

### Web 端用了什么技术？

> 现代 Web 管理端采用 Vue 3 + Vite + Element Plus + ECharts，源码在 `web` 目录，和移动端 API 共用同一个 Spring Boot 后端。原始 JSP 管理页面仍然保留，作为兼容版本。

### Web 端怎么运行？

> 演示环境已经把 Web 构建产物打进 war，直接访问 `http://localhost:8006/web/` 即可。如果要改前端代码，进入 `web` 目录执行 `npm install` 和 `npm run dev`，开发服务器会自动请求 8006 的后端接口。

### Excel 如何识别不同报表？

> 按文件名识别报表类型，按文件名中的 6 位年月确定会计期间；利润表按行次或项目名称映射字段；资产负债表按左右两栏识别年初/期末；科目余额和账龄按表头映射。重复导入会先清理同公司、同期间的数据。

### 数据转换做了什么？

> 将原始报表字段通过编码映射转换为标准科目编码，写入 `t_report_result` 和 `t_report`。移动端比率、趋势图和报表详情都读取标准结果，降低对原始 Excel 表结构的依赖。

### 权限怎么实现？

> 后台使用 HttpSession；移动端使用 token。菜单资源、角色权限和用户额外权限分别存放在 `t_sys_resources`、`t_sys_role_action`、`t_sys_user_action`，登录后加载菜单。

### 预测算法是什么？

> 损益预测使用历史月度数据的线性趋势，叠加费用率和增长调整；投资预测使用逐年收入、成本、折旧、利息、税费和现金流，计算 NPV、IRR 和回收期。模型是教学简化模型，报告中明确说明假设。

### 目前有哪些不足？

> 密码目前使用 MD5，移动端 token 存在内存中，投资模型还没有考虑营运资金垫支和残值税费；如果继续完善，会升级为 BCrypt、持久化 token、增加权限拦截和更完整的财务模型。

## 十二、现场故障处理

| 问题 | 处理 |
| --- | --- |
| 端口 8006 被占用 | 说明已有后端在运行，直接使用，不要重复启动 |
| 手机 App 网络失败 | 检查 USB，执行 `setup-adb-reverse.ps1`，再运行 App 基座 |
| 手机未识别 | 重新开启 USB 调试，重新允许授权，换数据线 |
| HBuilderX 无法运行真机 | 先用“运行到浏览器”展示移动端页面，再排查 USB |
| Web 页面 500 | 检查 MySQL80 是否运行，确认数据库 `financial_analysis` 已导入 |
| 报表没有数据 | 用 `demo-files` 重新导入，再点数据转换 |
| 教师要求看接口 | 用浏览器打开 `/api/health`，或用 Postman 调用 `/api/auth/login` 后带 token 请求 |
