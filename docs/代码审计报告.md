## 四、本次审计发现并修复的问题

1. MySQL 返回 `LocalDateTime` 导致 JSP 日期格式化失败，已统一转换为 `Timestamp`。
2. 新 Web 报表分页 SQL 的 `LIMIT` 参数顺序错误，已修复为 `LIMIT offset,size`。
3. 资讯 SQL 中 `upDate` 别名与 MySQL 关键字冲突，已改为 `up_date` 再转驼峰。
4. 驼峰字段被错误转成全小写，导致 `userName`、`viewNum`、`basiField` 等字段丢失，已修复。
5. JSON 同时输出 `userName` 和 `username` 的重复键，已修复。
6. 超级管理员角色权限表为空，已补充 92 条角色资源权限。
7. 新 Web 缺少编码映射和同步字典操作，已补充页面、API 和按钮。
8. 新 Web 入口被后台登录拦截，已放行 `/web/**`。

## 五、仍然存在的限制

1. 移动端还没有实际生成 APK/H5 产物。
2. 新 Web 暂未实现用户权限分配、字典明细编辑、转换结果列表，这三项仍可在旧 JSP 管理端操作。
3. 新 Web 的管理 API 目前只校验登录 token，没有按角色做接口级菜单权限拦截；JSP 页面有权限数据，但接口层还没有完整做 RBAC 强制校验。
4. 密码使用 MD5，移动端 token 存在内存中，适合实训，不属于生产级安全方案。
5. 投资预测是教学简化模型，未考虑营运资金垫支、残值税费和更细的融资安排。
6. `t_sys_role_action` 和 `t_sys_user_action` 可以管理，但新 Web 还没有完整的权限树编辑界面。
