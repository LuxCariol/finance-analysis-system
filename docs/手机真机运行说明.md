# 手机真机运行说明

本文只讲 **Android 手机真机运行**。电脑浏览器预览和手机真机的区别只有一个：手机不能使用 `localhost` 访问电脑上的后端，必须使用电脑的局域网 IPv4 地址。

## 一、运行结构

```text
Android 手机
    │  同一 WiFi
    ▼
电脑局域网 IP:8006
    │
    ▼
Spring Boot 后端
    │
    ▼
MySQL financial_analysis
```

手机端只负责显示页面，所有报表、比率、预测数据都从电脑上的后端获取，所以后端必须先启动。

## 二、准备条件

1. 电脑已启动 MySQL80。
2. 后端 war 已生成：

```text
D:\code\CodexProgram\ShixunCode\financial-analysis\backend\target\financial-analysis.war
```

3. Android 手机和电脑连接同一个 WiFi。
4. 手机已开启“开发者选项”和“USB 调试”。
5. HBuilderX 已解压，建议使用资料包中的 `HBuilderX.3.4.15.20220610.zip`。

## 三、第一步：启动后端

打开 PowerShell：

```powershell
cd D:\code\CodexProgram\ShixunCode\financial-analysis\backend
java -jar target\financial-analysis.war
```

看到类似下面的日志说明启动成功：

```text
Tomcat started on port(s): 8006
Started FinancialAnalysisApplication
```

先不要关闭这个 PowerShell 窗口。

在电脑浏览器打开：

```text
http://localhost:8006/admin/pc/login
```

能打开登录页，再继续下一步。

## 四、第二步：查找电脑局域网 IP

在 PowerShell 执行：

```powershell
ipconfig
```

找到当前 WiFi/以太网网卡的 IPv4 地址，通常是：

```text
192.168.x.x
10.x.x.x
172.16.x.x - 172.31.x.x
```

不要使用：

```text
127.0.0.1
localhost
```

例如查到的是 `192.168.1.20`，后面手机访问地址就是：

```text
http://192.168.1.20:8006
```

也可以运行项目里的脚本自动列出网卡地址：

```powershell
powershell -ExecutionPolicy Bypass -File D:\code\CodexProgram\ShixunCode\financial-analysis\tools\set-mobile-api.ps1
```

## 五、第三步：放行 8006 端口

如果 Windows 防火墙拦截了端口，手机会一直提示“网络连接失败”。

以管理员身份打开 PowerShell，执行：

```powershell
New-NetFirewallRule -DisplayName "Financial Analysis 8006" -Direction Inbound -Protocol TCP -LocalPort 8006 -Action Allow
```

如果不想改防火墙，也可以临时关闭当前网络下的防火墙进行课堂演示，但演示结束后要重新打开。

## 六、第四步：用手机浏览器验证后端

在手机浏览器输入：

```text
http://电脑IP:8006/api/health
```

例如：

```text
http://192.168.1.20:8006/api/health
```

正常情况下会看到类似 JSON：

```json
{"code":200,"message":"success","data":{"status":"UP","database":"financial_analysis"}}
```

如果手机浏览器都打不开这个地址，不要继续运行 HBuilderX，先检查：

- 手机和电脑是否在同一 WiFi。
- 是否误用了 `localhost`。
- Windows 防火墙是否放行 `8006`。
- 后端是否仍在运行。

## 七、第五步：修改移动端接口地址

打开：

```text
D:\code\CodexProgram\ShixunCode\financial-analysis\mobile\common\config.js
```

把 `API_BASE` 改成电脑 IP：

```js
export const API_BASE = 'http://192.168.1.20:8006'
```

注意：

- 末尾不要加 `/api`。
- 末尾不要加 `/`。
- 手机和电脑的 IP 必须对应同一个网络。

也可以直接运行脚本自动修改：

```powershell
powershell -ExecutionPolicy Bypass -File D:\code\CodexProgram\ShixunCode\financial-analysis\tools\set-mobile-api.ps1 -ApiHost 192.168.1.20
```

脚本修改后，重新运行移动端。

## 八、第六步：HBuilderX 运行到 Android 真机

1. 解压 `HBuilderX.3.4.15.20220610.zip`。
2. 运行 `HBuilderX.exe`。
3. 选择“文件 → 导入 → 从本地目录导入”。
4. 选择目录：

```text
D:\code\CodexProgram\ShixunCode\financial-analysis\mobile
```

5. 手机用 USB 连接电脑，确认手机弹出“允许 USB 调试”，点击允许。
6. HBuilderX 菜单选择：

```text
运行 → 运行到手机或模拟器 → 运行到 Android App 基座
```

7. 第一次运行如果提示安装“App 真机运行”插件，按提示安装。
8. 第一次运行会向手机安装 HBuilderX 标准基座，安装完成后自动打开 App。
9. 使用账号 `root`、密码 `123456` 登录。

如果 HBuilderX 提示“未检测到手机”，可以尝试：

- 换一根支持数据传输的 USB 线。
- 在手机开发者选项中关闭再打开 USB 调试。
- 在电脑安装手机厂商 USB 驱动。
- 使用 HBuilderX 的“运行到手机或模拟器 → 刷新设备列表”。

## 九、第七步：检查移动端页面

登录后依次检查：

1. 经营报告：健康分、营业收入、净利润、经营现金流。
2. 财务分析：资产负债、利润、现金流量、比率分析。
3. 报表详情：点击任一报表项目查看月度趋势。
4. 账龄分析：切换应付、应收、预付、预收等类型。
5. 损益预测：生成 6 个月预测。
6. 投资预测：快速测算和完整测算。
7. 个人中心：资料、企业信息和退出登录。

## 十、常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 手机 App 提示网络连接失败 | 仍使用 `localhost` | 改成电脑局域网 IP |
| 手机浏览器打不开 `8006` | 防火墙或 IP 错误 | 放行端口，重新查 IPv4 |
| 电脑浏览器正常、手机失败 | 手机和电脑不在同一 WiFi | 连接同一 WiFi |
| App 白屏 | HBuilderX 编译失败 | 查看 HBuilderX 控制台错误 |
| 登录提示账号密码错误 | 未初始化种子数据 | 执行 `seed_admin.sql` |
| 登录后没有报表数据 | 未导入报表 | 后台批量导入或等待首次启动自动导入 |
| 返回 401 | token 失效 | 退出后重新登录 |
| 端口被占用 | 旧后端进程仍在 | 关闭旧 Java 进程后重启 |

## 十一、课堂演示建议

为了避免现场环境问题，建议按下面顺序演示：

1. 电脑上先打开 Web 管理端并登录。
2. 用手机浏览器打开 `/api/health`，确认网络通。
3. 再用 HBuilderX 启动 Android 真机基座。
4. 登录后演示经营报告和财务分析。
5. 最后演示投资预测，展示 NPV、IRR 和逐年现金流。

如果教室 WiFi 不允许设备互访，可以让电脑开热点，手机连接电脑热点，然后把 `API_BASE` 改成电脑热点网卡的 IPv4 地址。

## 十二、WiFi 显示 ERR_ADDRESS_UNREACHABLE 时

如果手机浏览器打开 `http://电脑IP:8006/api/health` 显示 `ERR_ADDRESS_UNREACHABLE`，说明手机根本没有路由到电脑，通常不是代码问题。按下面顺序排查。

### 1. 先确认手机使用的是同一个 WiFi

在手机“设置 → WLAN → 当前网络”查看手机 IP。

电脑 WLAN 是：

```text
10.101.31.36
子网掩码 255.255.0.0
```

手机 IP 应该也是 `10.101.x.x`。如果手机显示的是移动数据 IP，关闭移动数据，重新连接 WiFi。

### 2. 判断是否是教室 WiFi 的设备隔离

在手机浏览器打开：

```text
http://10.101.0.1
```

如果连网关都打不开，说明当前 WiFi 禁止设备互访，或者手机没有连上这个网络。这种情况下不要继续改代码。

### 3. 方案一：USB + ADB 端口反向转发（最稳）

只要手机能通过 USB 连接并被 HBuilderX 识别，就可以绕过 WiFi 和防火墙。

1. 手机开启“开发者选项”和“USB 调试”。
2. USB 连接电脑，手机上点击“允许 USB 调试”。
3. 在项目根目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File D:\code\CodexProgram\ShixunCode\financial-analysis\tools\setup-adb-reverse.ps1
```

脚本会执行：

```text
adb reverse tcp:8006 tcp:8006
```

并把移动端接口地址改成：

```js
export const API_BASE = 'http://127.0.0.1:8006'
```

此时手机上的 `127.0.0.1:8006` 会被 USB 转发到电脑的 8006 端口。

4. 手机浏览器打开：

```text
http://127.0.0.1:8006/api/health
```

5. 返回 JSON 后，再用 HBuilderX 运行到 Android App 基座。

注意：拔掉 USB 线后，`adb reverse` 会失效。重新连接手机后，再运行一次脚本。

### 4. 方案二：放行 Windows 防火墙

右键“以管理员身份运行”PowerShell，执行：

```powershell
powershell -ExecutionPolicy Bypass -File D:\code\CodexProgram\ShixunCode\financial-analysis\tools\open-firewall-8006.ps1
```

也可以在项目根目录直接双击脚本并允许 UAC 提权。

### 5. 方案三：电脑开热点

如果教室 WiFi 有设备隔离：

1. Windows 设置 → 网络和 Internet → 移动热点，打开热点。
2. 手机连接电脑热点。
3. 在电脑执行 `ipconfig`，找到热点网卡 IPv4，常见为 `192.168.137.1`。
4. 修改 `mobile/common/config.js`：

```js
export const API_BASE = 'http://192.168.137.1:8006'
```

5. 手机浏览器先访问 `http://192.168.137.1:8006/api/health`。

电脑热点方式通常比教室 WiFi 更稳定，适合课堂演示。
